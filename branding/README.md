# Axiom branding

| File | Use |
| --- | --- |
| `logo.svg` | Mark and wordmark for light backgrounds (README, documentation). |
| `logo-dark.svg` | Mark and wordmark for dark backgrounds. |
| `logo-mark.svg` | The mark alone: avatars, social previews, slide corners. |
| `favicon.svg` | Browser tab icon; the mark reads down to 16 px. |

The mark is an "A" whose crossbar is the horizontal axis, with a single point at the apex: the starting
point everything else is derived from. Colors: indigo `#4f46e5` to teal `#0ea5a4`, white strokes, amber
`#fde68a` apex dot, wordmark `#1e1b4b` (light) or `#e0e7ff` (dark).

The wordmark uses the font stack `Inter, Segoe UI, Helvetica, Arial, sans-serif` and falls back to the
viewer's system font; use the mark alone where exact lettering matters.
