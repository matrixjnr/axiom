# Security policy

## Supported versions

Axiom is pre-release. No version is supported for production use yet, and fixes
land on `main` only. This section will list supported release lines once a
stable release exists.

## Reporting a vulnerability

Report suspected vulnerabilities privately. Do not open a public issue or pull
request with exploit details.

1. Use GitHub private vulnerability reporting:
   <https://github.com/matrixjnr/axiom/security/advisories/new>
2. If that is unavailable, email jonnyeinstein@gmail.com with the subject
   `Axiom security report` and a description of the impact, affected
   versions or commit, and steps to reproduce.

Never include credentials or private application data in a report.

## What to expect

- Acknowledgement within 7 days.
- An initial assessment within 14 days, and updates at least every 14 days
  until the report is resolved.
- Coordinated disclosure: a fix and advisory are published together, normally
  within 90 days of the report. Reporters are credited unless they prefer not
  to be.
