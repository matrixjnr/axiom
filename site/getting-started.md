# Getting started

Add the modules you need, write routes, and call `listen`. The [home page](index.md) shows a
complete application; these pages explain how an application is put together and how it is
served over HTTP.

- [Application programming model](programming-model.md): bootstrap, lifecycle and testing without ports.
- [HTTP listeners](http.md): addresses, limits, timeouts and shutdown.
